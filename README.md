# اسپرت جاوید — نسخه نمایشی

فروشگاه مدرن و راست‌چین لوازم اسپرت خودرو با تم تاریک/روشن، محصولات نمونه، سبد خرید، پرداخت آزمایشی و پنل مدیریت.

## اجرا

```bash
npm install
npm run dev
```

برای ساخت نسخه نهایی:

```bash
npm run build
```

## پنل مدیریت

از گزینه «ورود به پنل ادمین» در منوی بالای سایت استفاده کنید. این پروژه یک دموی فرانت‌اند است؛ ورود، پرداخت و داده‌ها آزمایشی هستند و برای استفاده واقعی باید به سرویس‌های بک‌اند، احراز هویت و درگاه پرداخت متصل شوند.
